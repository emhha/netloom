# 来源校验索引

本目录保存适配前文件的校验记录，不作为当前代码布局或功能清单。

- [source-manifest.json](source-manifest.json)：按匿名基线编号区分的原始文件 SHA-256；路径是相对于来源包布局的标识，不表示当前目录。
- [upstream-origin.md](upstream-origin.md)：补充的原始文件 SHA-256 记录。

校验值在整理时保持不变。代码适配后可能与原始哈希不同；这些记录既不声明来源项目使用本库，也不替代作者署名、许可证或再分发授权。公开上游资源的来源、版本和许可证保留在各资源目录，详见 [来源与许可](../SOURCES.md)。
